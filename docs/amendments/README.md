# Amendments to the MC-MED confirmatory preregistration

After the tag `mcmed-confirmatory-prereg-v1`, [../mcmed_confirmatory_preregistration.md](../mcmed_confirmatory_preregistration.md) is not edited in place. Each change is a new file `YYYY-MM-DD-<slug>.md` stating:
- timestamp;
- reason;
- whether any outcome or test result had been seen;
- scientific consequence.

A change made after the locked test was opened may invalidate the confirmatory status.
